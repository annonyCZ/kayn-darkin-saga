# Contributing
- Open an issue before large changes. Small fixes: just send a pull request.
- Run `godot --headless --path . res://tests/test_runner.tscn` and keep it green; add checks for new gameplay.
- GDScript: static typing, tabs, `class_name` only where needed. Comments in English.
- Assets: only original work or properly licensed (CC0/CC-BY/MIT...) content. Record each one in `docs/ASSET_REGISTER.md`
  with source and license. **No Riot Games, Black Myth: Wukong or other proprietary assets.**
- Mark original story additions as "original fan-made" so they stay distinct from established lore.
- By contributing you agree your work is released under the MIT license.
