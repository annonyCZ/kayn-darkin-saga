# Decisions
- Input actions are registered in code (scripts/core/settings.gd) so they are always valid and rebindable; the original hand-written project.godot input block was malformed.
- Scenes are generated by tools/build_scenes.gd but are normal .tscn files you can edit in the editor.
- Hitboxes poll overlaps each physics frame for deterministic hits, once per target per swing.
- Godot 4.5 used for verification; code is compatible with 4.7.
- Path profiles are data in scripts/player/kayn_paths.gd (enum + multipliers); GameState autoload owns the permanent choice and save file.
- Code comments in English (originals were Czech); say if you prefer Czech.
